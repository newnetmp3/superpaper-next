## Scope and verification standard

Base: `master` at `ffa92ba6b73485a76b3d89ac976bbca3fde297e1`.

Review is against GitHub repository source and GitHub Actions, not an assumed local checkout.

**Pass** means a dedicated headless regression test or existing automated check
exercises the named behavior. **Fixed** means a defect was identified and corrected
with regression coverage. **Not Verifiable** explicitly denotes a missing real
wx/GTK/KDE/Wayland/AMD Vulkan test: it is not a claim of success. Most entries
contain both an automated outcome and a hardware limitation.

## Defects identified and corrected

1. wx.ListCtrl's focused row differs from explicit selected source on GTK.
   Explicit replacement is tracked and reconciled against renderable source files.
2. A previous selected image could override a replacement, especially with multiple
   monitors or advanced group keys. Selection now checks each target's sources.
3. Apply used to persist `selected=` to a saved profile even when its saved
   `displayNpaths` did not include the unsaved replacement. Apply no longer
   changes the saved profile or live profile selection.
4. The preview formerly displayed only the newly chosen image rather than the
   full multi-monitor composition. It now uses the same resolved images as Apply.
5. Repeated identical source path strings serialized with `list.index` could
   emit duplicate `display0paths` and omit `display1paths`. Replaced with
   `enumerate`, keeping backward-compatible `displayNpaths` format.
6. Advanced group keys must use a stable order matching their source groups.
   Groups now serialize in sorted key order.

## Cleanup rules observed

Only verified inert code and a duplicated index-derivation algorithm were
removed or consolidated. The former generic directory chooser was already
removed by PR #30 and is asserted absent by `test_native_picker.py`.
Runtime dependencies were not removed because a headless scan cannot establish
the absence of platform-specific or dynamically loaded users. Old profile
parsing, CLI, Windows/macOS backends and wx event callbacks remain intact.

## Validation commands and limits

GitHub Actions CI runs `uv sync --frozen --group dev`,
`uv run ruff check --output-format=github`,
`uv run ruff format --check`, `uv run ty check`,
`uv run pytest -q --durations=10`, and a wheel build, resource check,
and installed CLI smoke test. CodeQL runs as a separate pull-request check.

The automated environment is Ubuntu with Python 3.14 and no native KDE
Wayland session or AMD GPU. Manual desktop verification remains necessary for
those system-dependent points. Inspect the latest checks on PR #31 for their
final results; the audit intentionally does not treat a queued check as passed.
